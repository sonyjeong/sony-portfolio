01 — A

A series, not a template

지점 마스코트 ‘코코’와 직접 촬영한 사진으로 회차마다 테마가 다른 시리즈 홍보물을 만들었습니다.

01 — B

Guest Connect Mission

처음 만난 게스트가 자연스럽게 말을 걸 수 있도록, 짝 찾기에서 경품 응모까지 이어지는 참여 구조를 설계했습니다.

01게임 참여권입장 시 회차 테마 그림이 담긴 카드 배부
02같은 그림 짝 찾기같은 카드를 가진 처음 보는 게스트와 팀 구성
03미니게임 도전스태프 인증 후 사격 · 링 던지기 · 푸즈볼
04경품 응모권많이 참여할수록 당첨 확률이 높아지는 구조

선착순 → 재참여형 · 인기로 미니게임이 조기 마감되자, 같은 그림 카드를 여러 장 준비해 새로운 파트너와 반복 참여하도록 바꿨습니다. 카드 테마는 이모지 → 바비 → 크리스마스 캐릭터 → 트럼프 카드로 회차마다 바꿨습니다.

Situation

아는 사람끼리만 대화가 오갔습니다

식음료와 스몰토크 위주라 새로운 교류로 이어지지 않았고, 범용 포스터로는 지점 행사의 개성이 전달되지 않았습니다.

Plan

참여 장벽을 낮추는 가격

타 지점 평균(약 2만 원)보다 낮게 설계했습니다.

  • RSVP ₩12,000
  • Walk-in ₩15,000
  • 무제한 음료 · 럭키드로우 포함
Action

운영까지 직접 책임졌습니다

  • 체크인 · 식음 · 게임별 업무 분담
  • 45분 단위 스태프 교대표 (국·영문)
  • 카테고리별 예산 · 정산 시트
Result

참여 인원 66.7% 증가

90명에서 150명으로 늘었고, 멤버가 데려온 지인이 다시 찾아와 등록하는 사례로 이어졌습니다.

01 — C

The first call is the first impression

신규 문의 고객에게 2년간 직접 회신하며, 이탈이 생기는 첫 30초를 다시 설계했습니다.

  1. 이름 확인“○○님 되시죠?” 광고 전화가 아님을 첫마디에 전달
  2. 문의 경로 안내“영어회화 스터디 컬컴 신촌점입니다”로 신뢰 확보
  3. 1분 양해“1분만 통화 가능하실까요?”로 부담 낮추기
  4. 가장 빠른 상담 제안필요한 정보만 전하고 바로 일정 제안
Result
1년차 회신2,241
2년차 회신5,062
지점 평균4%
내 전환율7%

누적 7,303건 회신 · 문의 → 상담 전환율 5% → 7% (조교 중 최고) · 미확정 사유를 타지점 희망 · 거절 · 허수로 분류해 광고 개선에 반영
